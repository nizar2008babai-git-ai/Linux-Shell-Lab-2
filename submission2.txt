Q13. What is the difference between * and ? in a wildcard?

The * wildcard matches any number of characters, while ? matches exactly one character.

Q14. Why do you need to run sort before uniq?

Because uniq only removes adjacent duplicate lines, so sort puts identical lines together first.

Q15. What does the permission string -rwxr-x--- allow for the owner, the group and others?

The owner can read, write and execute. The group can read and execute. Others have no permissions.
